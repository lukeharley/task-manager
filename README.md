# task-manager
App Android (Kotlin + Jetpack Compose) pensata per gestire i propri task.

## Funzionalità
- Task con titolo, descrizione, categoria, priorità, stima in minuti e scadenza (oggi, domani o data a scelta)
- Ricerca e filtri per categoria e priorità; filtri intelligenti (Premium)
- Completamento con "Annulla" immediato e archivio dei task completati
- Promemoria con notifica, che conserva l'orario quando si modifica il task
- Timer Focus (Base, Pomodoro, Deep Work, personalizzato)
- Statistiche, temi ed esportazione TXT/PDF (Premium)

## Stack
Room, DataStore, Hilt, Navigation Compose, Google Play Billing.

## Build
Aprire il progetto con Android Studio (JDK 17, SDK 35) ed eseguire la configurazione `app`.
